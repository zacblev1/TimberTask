# Contributing to Timber Task

Thank you for your interest in contributing to Timber Task! This document provides guidelines and instructions for contributing.

## Code of Conduct

Please be respectful and considerate of others when contributing to this project. Harassment or abusive behavior will not be tolerated.

## Getting Started

1. Fork the repository on GitHub
2. Clone your fork locally
3. Add the original repository as an upstream remote
4. Create a new branch for your feature or bug fix

## Development Setup

1. Make sure you have Rust and Cargo installed (https://rustup.rs/)
2. Build the project with `cargo build`
3. Run tests with `cargo test`
4. Run the application with `cargo run`

## Making Changes

1. Make your changes in your feature branch
2. Add tests for your changes when possible
3. Ensure all tests pass with `cargo test`
4. Ensure code formatting is correct with `cargo fmt -- --check`
5. Check for common issues with `cargo clippy`

## Submitting Changes

1. Push your changes to your fork
2. Submit a pull request to the main repository
3. Include a clear description of the changes and why they're needed
4. Update the README.md if needed

## Pull Request Process

1. Ensure your PR passes all CI checks
2. A maintainer will review your PR
3. Address any requested changes
4. Once approved, a maintainer will merge your PR

## Style Guidelines

- Follow Rust standard coding conventions
- Use descriptive variable and function names
- Comment your code when necessary
- Use the standard library when possible
